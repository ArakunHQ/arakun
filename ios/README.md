# Arakun for iOS

A native SwiftUI app for your sessions on the go: it pairs with Arakun the way the
phone page (`../phone/`) does and speaks the same protocol through the relay, end to
end encrypted. The computer and the relay need nothing new.

```
ios/
  project.yml        the Xcode project, generated by xcodegen
  Arakun/            the app: pairing, inbox, a live session, new session
  ArakunKit/         the protocol, testable on a Mac
    Sources/ArakunKit/E2E.swift        P-256 handshake, HKDF keys, AES-GCM frames (phone/e2e.js)
    Sources/ArakunKit/RelayLink.swift  the WebSocket to the relay, pings, {req}/{res}, {part} (phone/relay.js)
    Sources/ArakunKit/Models.swift     inbox, session, entries, state (core/src/phone/wire.rs)
```

## Building

Xcode 16 or newer and `xcodegen` (`brew install xcodegen`):

```sh
cd ios
xcodegen generate
open Arakun.xcodeproj         # pick your team under Signing, then run
(cd ArakunKit && swift test)  # the protocol against phone/test/vectors
```

Without a computer to pair with, launch with `-demo` (Debug builds only): sample
sessions fill the inbox. `-demoOpen s1` opens a session, `-demoNew YES` the New
session sheet, `-demoUnpaired YES` the pairing screen and `-demoMoods YES` every mood
of the raccoon side by side:

```sh
xcrun simctl launch booted com.arakun.ios -demo -demoOpen s1
```

## Design

The app follows the brand book (`.claude/skills/arakun-brand`): black and white grounds
with no tint, amber only for the one primary button and the live dot, Geist and Geist
Mono (`assets/fonts`, which `project.yml` reads from there), the line icons from `assets/icons`, and the
raccoon. Every color, font and corner comes from `Arakun/Theme.swift`; it
follows the system's dark or light setting.

The raccoon is alive, as on the desktop: `Arakun/Mascot.swift` is a smaller port of
`core/src/mascot.rs`, drawn from the same `assets/brand/mascot.json` (read from there,
not copied). It blinks and looks around, and shows the mood of what it
watches: thinking dots, reading while the agent works, a hopping question mark when a
session needs you, a tick when a turn ends, a shake and an exclamation mark on an
error, and sleep when the computer is offline or nothing happens for two minutes. A tap
makes it hop. One raccoon per screen: the pairing screen, the inbox header (the mood of
all sessions) and the composer of a session (that session's mood). With Reduce Motion
it holds still.

## CI and TestFlight

CI's iOS job (`.github/workflows/ci.yml`) runs `swift test` and builds the app unsigned
for the simulator when `ios/`, `phone/`, the mascot's drawing or the fonts change.
`.github/workflows/ios-release.yml` signs the app and uploads it to TestFlight: after
every release that is not a pre-release, or by hand (`gh workflow run ios-release.yml --ref main`). It needs an
App Store Connect API key in the `testflight` environment and skips until there is one;
the steps are at the top of that workflow.

## Pairing

Open the Phone tab in Arakun, choose the relay, and scan its code from the app (or
paste the link). The credentials stay in the Keychain on this device only.

## What it does

- The inbox: every session, the ones waiting for you first, grouped by project.
- A session, live: messages, tool calls with their output, plans, thinking.
- Send a prompt (queued while the agent works), Stop, allow or deny a permission,
  answer the agent's questions, load older entries.
- Start a session in any place the computer offers.

Not yet: photos, diffs, session settings, plan limits and push notifications (the
phone page's push is Web Push; native push needs APNs support on the computer).
