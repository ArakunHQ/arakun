## Antigravity, Send Feedback and a Session tab

- **Agents:** Antigravity is a new agent: install `agy`, sign in from Settings › Antigravity and pick its modes, models and thinking level in the New session tab.
- **Feedback:** Send Feedback… in the palette and Settings › Privacy tells us about a bug or an idea, and after an agent error Arakun asks what happened. Short surveys may show as a corner card, only with usage counts on.
- **Sessions:** The Session panel is now a Session tab of the Workspace panel, so the right side is one card. In the sidebar tree, Ctrl+click and Shift+click pick sessions, and + starts a session in any project.
- **Speed:** Typing a path in Add project, paging through long sessions from your phone and clicking in the sidebar, pins and to-dos no longer stall the window.
- **Web:** Web search and fetch stop when a site refuses them instead of trying another way around, and simple pages load faster.
- **Fixes:** The sidebar shows one heading above the tree. A pinned view whose extension is off leaves the Pinned list. A download cut off partway now fails instead of reading as empty.
