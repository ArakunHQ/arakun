## Plugins on your servers, a Help menu and sorted sessions

- **Servers:** Paired servers get the plugins, MCP servers, skills and MCP sign-ins you install on this computer, and a notice lists what was added. Discover's new Install in picker puts an install in every repo, this repo for everyone, or this repo just for you.
- **Sessions:** The session tree shows the latest session on top. Pick Latest, A–Z or By environment with the sort button in the sidebar heading or in Settings › Appearance.
- **Help:** A Help button beside Settings in the sidebar opens Send feedback…, Report a bug…, Request a feature… and the docs. Feedback you send reaches a person, who can write back if you leave an email.
- **Models:** In the model menu, pointing at a reasoning level previews it, and the whole bar row picks a level.
- **Look:** Menus, sheets, the find bar and other popups that appeared at once now slide or fade in like the rest. Turn this off with Reduce motion.
- **Speed:** While an agent works, Arakun draws fewer frames and uses less CPU, with animations that look the same.
