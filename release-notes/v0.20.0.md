## Keep machines out of spreading and act on many rows

- **Servers:** Each machine has a new Off choice next to Prefer, Normal and Avoid. Spreading across machines never picks a machine that is Off, but you can still choose it by hand.
- **Sidebar:** Hover a session that is not running to archive it with one click. Shift+click picks a range, and right-clicking a selection archives, closes or deletes every row in it.
- **Sign-in:** Every sidebar preset has the Sign in with GitHub row, now drawn as a button. If you paired a server or phone by link before 0.19, the app says how to reconnect: sign in, or pair over Tailscale or the same Wi-Fi.
- **Changes:** The Changes list does much less work while it watches a repository, most of all one with large untracked folders.
- **Fixes:** Pressing Esc while a session's first prompt waits for the agent no longer pauses the queue.
