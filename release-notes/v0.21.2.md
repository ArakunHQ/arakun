## Security fixes for sandboxes, the browser and phone

- **Sandbox:** A sandboxed agent can no longer get the app to run its own programs on your computer through a project's Git settings, including before you approve a push.
- **Browser:** The browser's debug port is off by default, so other programs can't take over your signed-in browser. Inspect (F12) opens the developer tools in a window of their own.
- **Phone:** Links and pictures in a transcript can no longer run code in the phone page.
