## Security fixes for the browser, email and phone

- **Browser:** An agent can only click, type or run scripts in a page that finished loading from your computer, even while the page is navigating away.
- **Email:** An attachment you approve is the one that gets sent, even if a file changes after you approve. The approval shows each attachment's size.
- **Agents:** Unattended runs only read scripts inside the workspace to judge them; any other script needs your approval.
- **Phone:** Pairing with the relay is signed in a way that can't be mistaken for another message.
