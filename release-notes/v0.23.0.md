## Richer phone notices and diffs on iOS and Android

- **Phone:** Notices say what happened: the agent's last message, the command waiting for permission, or the question. Server sessions stop sending notices while you are at your computer, and the iOS and Android apps show the files a session changed with their diffs.
- **Servers:** You can clone a pasted repository on a connected server from the project picker. A session you reopen on a server shows at once instead of loading blank.
- **Agents:** A session stays Working while its background subagents run. A resumed subagent keeps its row and transcript and shows its latest step instead of only "Thinking…".
- **Teams:** Owners can promote, demote and hand over a team. Invites say whether the invitee can see them yet, and an @bot answer names whose Claude Code wrote it.
- **App:** Your profile opens in its own dialog, Discover offers Sign in for plugins that need one, and feedback has a Help / support choice.
- **Fixes:** Secrets are hidden the same way everywhere, the Linux install adds a launcher entry and icon, the open session has no hover archive button, an idle window stops redrawing, and session titles no longer show the drawing hint.
