## Private secret cards and where your tokens go

- **Secrets:** An agent that needs a token or password asks with a private card, so the value never lands in the session, also on the phone and on servers. Arakun keeps its own keys and tokens in your system keyring, and secrets typed into a prompt stay out of titles, notifications and memory.
- **Usage:** The Usage tab has a "Where tokens go" section that shows what makes your Claude Code sessions large and opens the place to fix each one.
- **Agents:** Arakun's own commands in a session read as what they do, such as "Search memory", and password fields in an agent's question are masked.
- **Servers:** A server forgets an environment whose folder you removed outside Arakun, and old photos, transcripts and leftover files are cleaned up on their own.
- **Fixes:** Claude's task list shows again on the newest models. The phone settings explain what each notification switch does.
