## Cloud environments and secrets kept out of sight

- **Cloud:** You can make a cloud environment, or ask for access to one, from the Computers tab and on the phone. Its card shows whether it is awake and the hours left this month, with Stop, Wake and Remove.
- **Secrets:** Secrets show as stars in sessions until you click them, and copying one asks first. Arakun asks before an agent reads a `.env` or credential file, and warns before you send a key in a prompt.
- **Linear:** A delegated session shows the step it is on in the issue, links its pull request as soon as it exists, and lets you pick a question's answer from a list. Start a reply with `!` to interrupt the running turn.
- **Phone:** You can attach photos when you start a session, and the iOS and Android apps show the card where an agent asks for a secret. Traffic on your local network is now encrypted end to end.
- **Look:** Windows high contrast themes draw Arakun in the theme's own colors, and screen readers can find and use far more of the app.
- **Fixes:** A session on a server shows a sign-in button when its agent is not signed in there, and images you mention in your own prompts show in server sessions.
