## Saved project secrets and email sign-in

- **Secrets:** The secret card can save a key for the project, and agents can reuse it later without asking again. Settings › Project › Saved secrets lets you rename, replace or remove them, and set a variable each agent starts with.
- **Account:** You can sign in with a code sent by email instead of GitHub, on app.arakun.dev and in the iOS and Android apps.
- **Linear:** A delegated session reads the whole issue, with its uploads as files, and moves it to In progress when work starts. Linear shows the session's plan, its current step and what it did, and the session stops when you unassign Arakun or close the issue.
- **Settings:** Search in Settings filters down to the matching rows, and the palette lists every setting and every menu command. With nothing typed, the palette shows what you can type.
- **Shortcuts:** Settings › Keyboard shortcuts lists every shortcut, and the palette uses the same keys as the window. The GitHub tab offers to install or sign in to the GitHub CLI when it is missing or signed out.
- **Fixes:** Images you paste into a server session reach the agent there, flowchart lines and labels no longer cover other boxes, and survey answers are sent without any keys in them.
