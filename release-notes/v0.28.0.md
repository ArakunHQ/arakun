## A sidebar for what needs you, and password managers

- **Sidebar:** A Needs you list at the top shows every session that waits on you or failed, across projects. The default sidebar names Runs, Branches and GitHub and puts the other views in More views, and the folded sidebar shows one tile per project with its sessions on hover.
- **Secrets:** The secret card and Settings › Project › Saved secrets take a 1Password reference instead of a value, so your keys stay in your password manager.
- **Linear:** Sessions at once in the Linear tab sets how many delegated sessions run on each computer, up to 20. A session that waits for an answer or for background work frees its place, and a session waiting in the queue no longer shows as stopped in Linear.
- **Cloud:** Cloud environments can clone your private repositories and push branches once you install the Arakun Cloud GitHub App.
- **Accessibility:** Screen readers can read the chat and the terminal, and announce when a session needs you, finishes or fails.
- **Fixes:** Hovering a session in the sidebar shows its archive button again on macOS, and the server install script works when GitHub's release page is down.
