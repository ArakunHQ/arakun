## Session outline, phone settings and files for servers

- **Sessions:** A long session shows an outline on its right edge: drag it to scroll, or click a turn to jump to its prompt. Images that tools return, such as browser screenshots, show under the tool row instead of "[image]".
- **Composer:** Attached files show as chips next to image thumbnails. In a server session, any file you attach now goes to the server with the prompt, not just images.
- **Phone:** The iOS and Android apps let you change a session's model and reasoning, pick them when you start one, and see your plan limits. Android can attach photos, and the phone page lets you retry or take back a prompt the server never got.
- **Cloud:** A cloud environment can pick up Linear issues delegated to Arakun, and wakes up when one arrives.
- **App:** Settings has switches for desktop notifications, memory and notes to agents, and a new Tabs section for the optional tabs. The Marketplace lists community widgets, and `arakun doctor` shows which agents and tools are missing.
- **Fixes:** Teams says when the keyring, not the network, is the problem, and you can hide invites from a team. Pasted images that nothing uses are deleted after 7 days. A `chmod --reference` write is checked like any other.
